# Framework Rules

Folder Structure:

features/
steps/
pages/
fixtures/
components/
utils/
test-data/

Rules:

1. Feature File → Business Layer
2. Steps → Mapping Layer
3. Pages → Action Layer
4. Utilities → Common Layer
5. Assertions → AssertionUtil
6. Logging → Logger
7. Waits → WaitUtil

Always follow BDD + POM approach.
